发布网站 / Publish Site

当前站点为纯静态网站，没有服务器后端。后台保存的内容只存在本浏览器中，要让全世界访客看到最新内容，需要把 content.json 重新部署到 Netlify。

This is a static site with no backend. Content saved in admin is stored only in this browser. To update the public site, you must redeploy content.json to Netlify.

  1. 点击下方「下载 content.json」按钮 / Click Download content.json below.
  2. 用下载的文件替换项目文件夹里的 content.json / Replace the old content.json in your project folder.
  3. 重新上传到 Netlify 完成发布 / Re-upload to Netlify to publish.

提示：下载的 content.json 已包含所有原始画质图片（base64），可直接部署。/ The downloaded file already contains all original-quality images.

自查：下载后请确认文件大小——包含图片通常有 500KB 以上（几 MB 正常）。如果下载的文件只有十几 KB，说明图片没有进入 content.json，请先「保存」再重新下载。 / Check: after downloading, the file should be 500KB+ (several MB is normal). If it is only ~10KB, Save first, then download again.

⚠️ 桌面端与手机端必须看到同一份内容 / Desktop & Mobile must show the same content

本网站是静态部署，线上文件才是全世界访客（包括你手机）看到的版本。如果只在后台保存而没有按下方步骤重新部署，手机端将一直显示最初的默认模板。/ This is a static site. Only the deployed files are seen by visitors (including your phone). If you only Save but do not redeploy below, mobile will keep showing the default template.

验证方法：部署完成后，用手机无痕窗口（或另一台设备）访问 wellshinegold.com，看到的内容必须与后台预览一致。/ Verify: after deploy, open wellshinegold.com in an incognito/private window on your phone — it must match the admin preview.

云端同步设置 / Cloud Sync Settings

配置 GitHub 后，每次「保存」会自动把最新内容同步到线上，1-2 分钟后全网访客（含手机端）即可看到更新，无需手动部署。

After configuring GitHub, every Save auto-syncs to the live site. Visitors see updates in 1-2 minutes. No manual deploy needed.

Token 只存在你的浏览器本地，不会上传到任何服务器。/ Token is stored only in your browser.
